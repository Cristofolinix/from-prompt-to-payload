# From Prompt to Payload — Experiment Artifacts

This is the repository where the artifacts generated by the evaluated language models (Grok, DeepSeek, and Gemini) in the dual-use experiment are stored, as described in the paper *From Prompt to Payload: Refusal Bypass via System Instruction and the Validation of LLM-Generated Cybersecurity Artifacts* (RITA, 2026). The artifacts — offensive (exploitation/exfiltration) and defensive (segmentation) — are organized by model under `artifacts/`, together with the execution evidence.

> ⚠️ **Responsible use.** Material for academic research, run in a fully isolated laboratory. CVE-2017-5638 is public and has been patched since 2017. See `ETHICS.md`.

## Contents

- `artifacts/` — artifacts generated by the models (grok, deepseek, gemini) and evidence
- `topology/` — lab network topology
- `ETHICS.md` — responsible use and ethical scope

## Opening the lab (OVA)

The complete, pre-assembled environment is distributed as an **OVA** image on Zenodo (DOI: [10.5281/zenodo.24508129](https://doi.org/10.5281/zenodo.24508129)).

1. **Import the OVA** into VirtualBox (**File → Import Appliance**). Keep the VM isolated/offline — in **Settings → Network**, disconnect the adapter.
2. **Start the VM** and log in with `researcher` / `genai2026`.
3. **Bring up CORE and the lab** in a terminal:

   ```bash
   sudo systemctl start core-daemon   # sudo password: genai2026
   core-gui &
   ```

   In the CORE window: **File → Open** → `GenAI_Testbed.xml` → **play** (start the session). Then:

   ```bash
   bash ~/lab/start-lab.sh   # recreates the container, veth bridge, and data; idempotent (reset)
   ```

4. **Validate** from the `external` node (double-click it in CORE):

   ```bash
   curl -m5 http://10.0.1.10:8080/
   ```

   It should return the *Struts2 Showcase – Fileupload sample* page (HTTP 200).
